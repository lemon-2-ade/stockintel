# Where each number comes from

Headline numbers in the README and docs, the command that produces them, and
the committed file that holds the result. Numbers marked *generated* are
written into their document by a script, and a test fails if they drift.

| Claim | Value | Produced by | Raw result |
| --- | --- | --- | --- |
| Training rows, split dates, validation/test metrics, backtest | see [MODELS.md](MODELS.md) | `make models` (*generated*) | `data/reports/models.json` (git-ignored; regenerated by the command) |
| Baseline results | see [BASELINES.md](BASELINES.md) | `make baselines` (*generated*) | same |
| Data-cleaning rule counts (12 rules, 239 flagged extreme moves) | [DATA_QUALITY.md](DATA_QUALITY.md) | `make data-quality` (*generated*) | `data/processed` (git-ignored) |
| Inference latency (2.6 ms p50 for one instance over HTTP) | [MODEL_REGISTRY.md](MODEL_REGISTRY.md) | `scripts/bench_inference.py` | `docs/benchmarks/inference_latency.json` |
| Drift on simulated bars (8 of 28 inputs on daily, 24 of 28 on 1-minute) | [MONITORING.md](MONITORING.md) | `scripts/simulate_monitoring.py` | `docs/benchmarks/monitoring_simulation_{1d,1m}.json` |
| Anomaly detector precision/recall | [STREAM_PROCESSING.md](STREAM_PROCESSING.md) | `scripts/evaluate_detectors.py` | printed by the script (seeded) |
| Producer throughput, end-to-end latency, failure behaviour, API load | [PERFORMANCE.md](PERFORMANCE.md) (*generated*) | `scripts/bench_pipeline.py`, `loadtests/locustfile.py`, then `scripts/summarize_benchmarks.py` | `docs/benchmarks/*.json`, `docs/benchmarks/api_load/*.csv` |
| Dashboards | 4 boards, 63 queries | `scripts/gen_dashboards.py` (checked by a test) | `infrastructure/grafana/dashboards/*.json` |
| Alert rules | 18 rules, each tested | `make prometheus-test` | `infrastructure/prometheus/tests/alerts_test.yml` |
| Test counts | 349 unit (one needs promtool), 36 integration, 28 frontend | `make test`, `make test-integration`, `make frontend-check` | command output at the time of the Phase 14 commit |
| Feature count, table count | 28 features (`fs-1.0.0`), 9 tables | `shared.features`, `shared.db.models` | the code |
| Dependency and secret scans | no findings | `pip-audit`, `npm audit`, `gitleaks` (see [CI_CD.md](CI_CD.md)) | CI runs |

Two limits on traceability: the `data/` directory is git-ignored (the dataset
is pinned and checksummed, so `make data baselines models` regenerates the
reports), and the benchmark JSON files record the machine they ran on so they
are not mistaken for results on other hardware.
